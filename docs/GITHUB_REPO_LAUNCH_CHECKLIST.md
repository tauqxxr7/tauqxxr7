# GitHub Repo Launch Checklist

Use this checklist before making a repository public or pinning it on your profile.

## Metadata

- Add repo description
- Add repo topics
- Choose a clean repository name
- Verify default branch is correct

## README Quality

- Add a strong README
- Add clear project identity
- Add problem / solution
- Add features
- Add tech stack
- Add architecture diagram or flow
- Add setup instructions
- Add usage section
- Add deployment status
- Add future improvements
- Add author / contact

## Assets

- Add screenshots or a demo GIF
- Verify image paths render correctly on GitHub
- Remove broken links or placeholders you no longer need

## Config / Safety

- Add `.env.example`
- Confirm no secrets or API keys are committed
- Add `.gitignore` entries for env files, databases, and build artifacts
- Add license if appropriate

## Engineering Signal

- Show frontend/backend separation where relevant
- Highlight AI, API, backend, or systems depth clearly
- Include testing or validation commands when available
- Mention deployment target honestly

## Pinning Decision

- Pin only if it strengthens your profile
- Do not pin unfinished or weak repos over stronger projects
- Prefer flagship AI product, backend/system-design project, and best full-stack project mix
