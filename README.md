## About Me

I build AI-first products with a full-stack mindset. That means thinking beyond prompts and demos into usable interfaces, clean backend architecture, deployable APIs, and workflows that feel like real products.

Most of my work sits around GenAI applications, agent-like systems, and practical tools for education, productivity, support, and career growth. I am especially interested in products that combine strong UX with reliable AI integration.

> Suggested GitHub bio: `AI & Full-Stack Developer building GenAI products with Next.js, Node.js, FastAPI, Gemini, and real-world agent workflows.`

## What I'm Building

- GenAI products that solve specific user problems instead of acting like generic chat wrappers
- Full-stack systems with separate frontend and backend architecture
- AI workflows designed for real-world usage, deployability, and maintainability
- Projects that showcase practical product engineering across UI, API, and model integration

## Flagship Project

### Scholr

**An AI-powered academic productivity platform designed to help students generate notes, solve doubts, research faster, and track learning history.**

**Problem**

Students often switch between scattered tools for research, notes, and concept clarification, which makes learning slower and less structured.

**Solution**

Scholr brings research assistance, notes generation, doubt solving, and persistent history into one product-style workflow.

**Key Features**

- Notes generation
- Doubt solving
- Research assistant
- Persistent history
- Scalable product direction for a broader academic operating system

**Tech Stack**

- Next.js
- TypeScript
- Tailwind CSS
- FastAPI
- Python
- Gemini API

## Featured Projects

### `ai-career-copilot`

**Problem**

Students and freshers often know how to code but struggle to translate that into a strong resume, interview preparation plan, and realistic skill roadmap.

**Solution**

A GenAI career assistant that analyzes a profile, identifies strengths and gaps, suggests interview prep, and generates practical next steps.

**Key Features**

- Resume analysis
- Skill-gap detection
- Interview question generation
- Project recommendations
- Roadmap generation

**Tech Stack**

Next.js, React, Node.js, Express, Gemini API, Render, Vercel

- Live demo: Deployment in progress

### `policypilot-agent`

**Problem**

Internal support teams spend time answering repetitive policy and support questions, while generic chatbots often lack grounding and safety controls.

**Solution**

An enterprise AI support agent with FAQ lookup, policy assistance, support routing, summarization, and safe-response logic.

**Key Features**

- FAQ lookup
- Policy assistance
- Support routing
- Summarization
- Safe refusal layer

**Tech Stack**

Python, Flask, Gemini API, HTML, CSS, JavaScript

- Live demo: Deployment available in project README
- Source code: [policypilot-agent](https://github.com/tauqxxr7/policypilot-agent)
- Screenshot/demo: Included in repo README

### `crisismind-lite`

**Problem**

People facing urgent digital or personal safety issues need immediate structured guidance, not a long generic chatbot answer.

**Solution**

A focused AI triage experience that classifies crisis type, severity, next actions, and a safety note in a fast, readable format.

**Key Features**

- Structured first-response output
- Safety-first UX
- Fallback guidance
- Lightweight deployment model

**Tech Stack**

Node.js, JavaScript, HTML, CSS, Gemini API

- Live demo: Deployment in progress
- Source code: [crisismind-lite](https://github.com/tauqxxr7/crisismind-lite)
- Screenshot/demo: Included in repo README

## System Thinking / Architecture

I like building with a clear separation of concerns:

```text
User -> Frontend -> Backend API -> AI Layer / Tools -> Structured Response -> UI
```

That usually means:

- separate frontend and backend architecture
- explicit environment configuration
- deployable app structure
- maintainable project organization
- model integration with guardrails or routing where needed
